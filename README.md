# 中学音楽ワーク

ZIPを解凍して index.html をブラウザーで開くと練習できます。

## GitHub Pages

1. 解凍したファイルをリポジトリにアップロードし、main にコミットします。index.html をリポジトリ直下に置きます。
2. Settings の Pages を開き、Source を Deploy from a branch にします。
3. main と /(root) を選んで Save を押します。
4. 公開されたURLをスマートフォンで開きます。

[GitHubの公開手順](https://docs.github.com/ja/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## 範囲と出典

教育出版『中学音楽 2・3上 音楽のおくりもの』の指定範囲は40〜43、48〜54ページ。写真で確認できたのは教科書40・41ページと「越天楽」「羽衣」の鑑賞プリントです。唱歌の設問は基礎を扱う補足です。橋掛かりと揚幕の役割の説明には一般的な能舞台の補足知識を使用しています。

学習記録は開いているブラウザーに保存されます。履歴を消去する場合は「学習記録をリセット」を押します。
